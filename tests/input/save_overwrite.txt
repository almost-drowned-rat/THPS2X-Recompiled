# Needs an existing save (save_new.txt). From this menu the game builds the save screen in "new save" mode
# (mode 1 at 0x0010CB8D; "overwrite" = mode 3 only after the in-game path, previous state 0x16 at 0x0010CB45),
# so keeping the name ends in "a file named CAREER A already exists" -- game logic, deterministic since the
# stage 3 relift. tests/storage.ps1 step 5.
